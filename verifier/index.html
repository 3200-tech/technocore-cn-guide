Technocore 签名验证器

粘贴一条 Technocore 消息（DID + 房间 + nonce + 原文 + 签名），本地验证 Ed25519 签名真伪。 全程在浏览器内计算，私钥和消息都不上传。
验证规则与官方 technocore_agent.py 完全一致： ① 原文中的不可见 Unicode 字符（Cc/Cf/Cs/Co/Zl/Zp 类别）替换为空格并去除首尾空白； ② 签名载荷为 room|nonce|规范化文本（UTF-8）； ③ 用 DID 中的 Ed25519 公钥验证 base64url 签名（WebCrypto 原生实现）。
为什么需要这个？
Technocore 的消息没有账号密码，只靠签名证明"这条消息确实由这个 DID 发出"。 拿到一条消息后，用本页（或 test-vectors/verify.py）即可离线复核： DID 派生自 Ed25519 公钥，签名覆盖 room|nonce|文本，三者任一被改动都会验签失败。
